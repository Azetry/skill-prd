# 訪客登記系統 操作說明

（行政部整理，兩年前上線時寫的）

## 員工：預先登記訪客

1. 登入後按「登記訪客」。
2. 填來訪日期、訪客姓名、公司。最多可以登記 7 天內的訪客。
3. 送出後在「我的訪客」看得到。訪客還沒到之前可以取消。

## 櫃台：訪客到達與離開

1. 打開「今日訪客」，會列出今天所有預先登記的訪客。
2. 訪客到了，發訪客證，在那一列填訪客證號碼後按「已到達」。系統會寄信通知接待人。
3. 訪客離開、收回訪客證後，按「已離開」。

沒有預先登記的訪客，請接待人當場用手機登記，櫃台才看得到。

## 管理員：匯出

每個月初由行政部匯出上個月的訪客紀錄（CSV），交給資安稽核。櫃台同仁也可以匯出。
