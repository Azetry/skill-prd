# 2.5 模組 2.0 取還車

總務交鑰匙與收車時各按一次，同仁還車時填里程。這個模組解決「月底對里程要一本一本翻」。

| 功能點 | 狀態 | 階段 |
|---|---|---|
| 2.1 取車 | <span class="status new">新增</span> | 二 |
| 2.2 還車 | <span class="status new">新增</span> | 二 |

## 2.1 取車

總務交鑰匙時，在當天的清單上按「已取車」。只有已核准、而且開始時間在今天的預約會出現按鈕。

規則的例子：上一次還車是 48,120 公里，這次填 48,215 可以送出；填 48,100 送不出去。

## 特殊情況

<ol class="cases">
<li><b>里程比上一次少</b><span>欄位下方顯示「不能小於上一次的 48,120 公里」；不送出。</span></li>
<li><b>超過預約的結束時間還沒還車</b><span>總務的清單把這一筆標成「逾時」；這輛車之後的預約照常保留。</span></li>
</ol>

## 驗收條件

1. 總務對今天已核准的預約按「已取車」，這一筆的狀態變成「使用中」。
2. 同仁填的里程大於上一次還車的里程，送出後狀態變成「待總務確認」。
3. 同仁填的里程小於上一次，看到上一次的里程數字，狀態不變。
4. 總務按「確認還車」後，行政主管在當月使用紀錄看得到這一筆和它的里程。
