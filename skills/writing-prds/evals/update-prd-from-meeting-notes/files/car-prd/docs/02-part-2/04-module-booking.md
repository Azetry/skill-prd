# 2.4 模組 1.0 預約

同仁送出預約、總務核准。這個模組解決「到了總務室才知道沒車」。

| 功能點 | 狀態 | 階段 |
|---|---|---|
| 1.1 送出預約 | <span class="status new">新增</span> | 一 |
| 1.2 總務核准 | <span class="status new">新增</span> | 一 |

規則的例子：11/26（四）09:00 到 11/28（六）18:00 是 3 天，可以送出；11/26（四）09:00 到 11/30（一）09:00 超過 3 天，送不出去。

## 1.2 總務核准

總務的清單列出所有「等待核准」的預約，照開始時間排序。每一筆有「核准」和「退回」兩個按鈕；按退回時要填原因，同仁在自己的預約上看得到。

## 特殊情況

<ol class="cases">
<li><b>同一輛車的時段重疊</b><span>時段欄位下方顯示「這個時段已有預約（11/26 13:00–17:00）」；不建立預約。</span></li>
<li><b>時段超過 3 天</b><span>時段欄位下方顯示「一次最長 3 天」；不建立預約。</span></li>
<li><b>同一人同一時段已有另一筆預約</b><span>顯示「你在這個時段已經預約了 ABC-1234」；不建立預約。</span></li>
<li><b>總務退回時沒填原因</b><span>原因欄位下方顯示「請填退回原因」；預約維持等待核准。</span></li>
</ol>

## 驗收條件

1. 同仁選一個沒有人預約的時段（不超過 3 天）並送出，看到「已送出，等待總務核准」，總務的清單出現這一筆。
2. 同仁選的時段和同一輛車已有的預約重疊，送出後看到重疊的那一筆的時間，清單沒有新增。
3. 同仁選 11/26 09:00 到 11/30 09:00，送出後看到「一次最長 3 天」。
4. 總務按退回並填「當天車輛送保養」，同仁在自己的預約上看到這個原因。
